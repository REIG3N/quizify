# Quizify

Application de quiz en ligne de commande, écrite en Python.
Chaque utilisateur choisit un thème, répond aux questions et
retrouve l'historique de ses scores.

![Menu](docs/menu.png)
![Partie en cours](docs/partie.png)
![Fin de quiz](docs/fin.png)

## Requirements

- Python 3.11 ou supérieur

## Lancement

```bash
git clone git@github.com:REIG3N/quizify.git
cd quizify
python3 main.py
```

## Fonctionnalités

- Quiz par thème (Python, Bash, Git)
- Gestion des utilisateurs
- Sauvegarde des scores avec date, par utilisateur et par thème
- Questions et données stockées en JSON
